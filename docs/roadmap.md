# Roadmap

## Phase 1

- Stabilize the new `src/quantresearch` package as the canonical research core.
- Add richer synthetic and sample financial datasets for offline demos.
- Expand statistical testing coverage and model benchmarking utilities.

## Phase 2

- Implement full PyTorch training loops for LSTM, GRU, and Transformer forecasters.
- Add regime-specific model routing and meta-labeling support.
- Introduce multi-asset portfolio environments for PPO and DQN.

## Phase 3

- Add Hydra or OmegaConf-driven large-scale experiment sweeps.
- Persist research artifacts to object storage and model registry backends.
- Publish polished dashboards and PDF-style research reports from automated runs.
